Sites & Sistemas Web

Projetos de sites e sistemas web desenvolvidos com foco em interfaces, funcionalidades e experiências de usuário.

HeroManager

Projeto desenvolvido como um sistema web para gerenciamento de uma equipe de heróis. A aplicação permite cadastrar e autenticar usuários, consultar heróis e visualizar informações como classe, habilidades, força, defesa e velocidade. Também é possível montar uma equipe com até cinco heróis ativos, enquanto os demais ficam armazenados na base, permitindo trocar, adicionar ou remover membros conforme a necessidade. O projeto envolve desenvolvimento de interface web, criação de funcionalidades de gerenciamento e integração com banco de dados, utilizando Python com Flask no back-end e HTML, CSS e JavaScript no front-end. Para acessar o código e a estrutura do projeto, clique aqui.

MindSpace

Projeto acadêmico desenvolvido em equipe com a proposta de criar uma solução digital voltada à saúde mental. O sistema foi pensado para facilitar o acesso ao atendimento psicológico, considerando dificuldades como a alta demanda dos serviços públicos, custos de consultas particulares e limitações de deslocamento e horários. Durante o projeto, foram estudados o domínio da saúde mental e da telepsicologia, identificados os principais problemas e definidas funcionalidades e protótipos para a solução proposta. O trabalho também envolveu o planejamento das interfaces e da experiência de uso do sistema, buscando tornar o atendimento psicológico mais acessível e organizado. Para acessar o código e a estrutura do projeto, clique aqui.

Projetos desenvolvidos para execução no terminal, com foco em lógica de programação, estruturas de dados, funções, orientação a objetos e interação por linha de comando.

Sistema de gerenciamento escolar

Desenvolvi um sistema de gestão escolar em Python para a disciplina de Programação I, simulando o funcionamento de uma instituição de ensino com gerenciamento de alunos, professores, turmas e disciplinas. O projeto permitiu aplicar conceitos de Programação Orientada a Objetos, encapsulamento, modelagem de classes, regras de negócio, validação de dados e tratamento de exceções, além de desenvolver a organização e estruturação de um sistema baseado em requisitos acadêmicos. Para acessar o código e a estrutura do projeto, clique aqui.

Calculadora de Treino e Metas Fitness

Desenvolvimento de uma Calculadora de Treino e Metas Fitness em Python, criada para realizar cálculos básicos relacionados a IMC, hidratação, gasto calórico e metas diárias de exercício. O projeto foi desenvolvido por meio de um menu interativo, permitindo aplicar na prática conceitos como variáveis, expressões aritméticas, estruturas condicionais, estruturas de repetição, entrada e saída de dados e organização do código.
